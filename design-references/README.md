# Design references

Local copies of the reference material supplied by the project owner, used only to study motion, layout and atmosphere.
The media files are git-ignored and are **not** part of the published website.

- `videos/promo-logo-intro.mp4`: promotional reference (light-streak logo reveal, glowing phone, map with route). Inspired the intro's comet trace, the glowing phone rim and the discovery-city motif. Its third-party logos and UI were not reproduced.
- `videos/creative-text-animation.mp4`: kinetic text reference (baseline draws, outlined letters rise, fill, floor reflection, tumbling letter). Inspired the intro wordmark sequence.
- `videos/ui-dashboard-transitions.mp4`, `videos/website-3d-gallery-transitions.mp4`, `videos/landing-scroll-animations.mp4`: earlier motion references.
- `images/palette.png`: the six brand colours.
- `images/green-plug-ev-showcase.png`: brand atmosphere reference.
- `previous-build/`: the earlier website ZIP, used for product information only.
- `frames/`: contact sheets extracted from the videos.
